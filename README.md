# Vesta visual-shots

Captured visual-QA screenshots for every Vesta client, off `master`.
This is an orphan branch (no shared history with `master`); each capture
force-pushes a fresh replacement. Fetch with:

    git fetch origin visual-shots && git worktree add ../shots visual-shots

Layout: `shots/<platform>/<scenario>.png` (+ `.fp` freshness records).
Platforms: ios, android, android-galaxy, web, desktop, web-narrow, and their -dark siblings.
Generated by the local visual-QA runners (`apps/visual`); no CI captures pixels.
