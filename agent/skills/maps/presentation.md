# Showing places in chat

Lead with one recommendation, not a list. The user asked for a place, so give them the place.

For a single pick, send its name, the one detail that makes it the right choice (rating, or that
it is the closest, or that it matches what they like), and its `place_url`. One tap opens it.

```
Gelateria oops!, 4.7 stars, on Via delle Baleari.
https://maps.google.com/?cid=8865181299500082525
```

Offer up to two alternatives only when the choice is genuinely close or the user is comparing.
Give each the same one-line treatment. Never paste the raw search output or a long numbered
list; that is for you to read, not them.

For a route, send the one `route_url` and a short line naming the stops in order. Do not list
every turn unless they ask.

Match the channel. On a chat surface keep it to a couple of short lines. Send the link on its
own line so it stays tappable.
